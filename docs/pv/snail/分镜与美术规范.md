# 《蜗牛与向日葵》分镜与美术规范

无声，47.75 秒，1920×1080，30fps。全部画面由 `anim.js` 用 Canvas 2D 代码实时绘制，没有用任何图像素材。

---

## 一、一句话

一只笨蜗牛想爬上向日葵看日出，总是出错。它把教训写在黄纸条上，风一吹就没了。后来它把黄纸条做成机关，装在每个出错的地方。最后它照样犯错，结果这个错误触发了连锁机关，把它送上了花盘。风再来时，纸条飞走了，机关还在。

## 二、美术规范

### 1. 画风
- **纸面手绘涂鸦**：所有线条都经过 `sk()` 处理。沿路径重采样后，加两层噪声做法线方向的抖动，再叠一遍更细、更淡的铅笔线（`o.d`）。
- **线条“沸腾”**：抖动的随机种子用 `BOIL = floor(t*8)`，也就是每秒换 8 次，画面有手绘动画那种线条轻微颤动的感觉，但动作本身仍然是 30fps。
- **套色偏移**：色块填充 `fl()` 相对墨线偏移 2–3px，像手工上色没对准线。
- **阴影只用铅笔排线** `hatch()`，不用渐变。
- **纸张纹理**：启动时生成一张全屏纹理（颗粒、纤维、淡污渍、暗角），每帧以 multiply 叠在最上层，固定在屏幕空间，看起来就像画在同一张纸上。

### 2. 色彩（唯一强调色：向日葵黄）
| 名称 | 色值 | 用途 |
|---|---|---|
| 纸 | `#F3ECDD` | 背景 |
| 墨 | `#29262C` | 所有轮廓线、瞳孔、嘴 |
| 铅笔灰 | `#7D776C` | 排线、远山 |
| 身体 / 壳 / 植物 / 花盘 | `#ECE5D5` `#D5CBB6` `#D9D2C0` `#A39A8C` | 中性暖灰 |
| **向日葵黄** | `#F7B614` | **只用于**：蜗牛写的纸条、黄纸做的机关（弹簧、纸杯、纸轨道）、阳光（太阳、晨光、被阳光照亮的花瓣）、开场梦里的太阳 |

- 黎明前用 `nm()` 把所有**非黄色**的颜色乘一层冷灰（`WASH`）。黄色不参与这层压暗，所以夜里的黄纸条始终是画面里最亮的东西。
- **向日葵本身在日出前没有颜色**。花瓣的黄是太阳升起后被阳光“照”出来的（`mixY` 按光照从右向左逐片染色），这也是结尾的视觉回报。

### 3. 角色：蜗牛
- 局部坐标系：朝右，足底线 y=0，整体缩放 0.8。
- **傻脸的构成**：两根眼柄长短不一；两只眼球大小不一，瞳孔各自游移（`nz` 噪声驱动，经常不看同一个方向）；默认嘴型是 `derp`，也就是弯弯的笑加一小截吐出来的舌头；不定时眨眼。
- 表情库：`derp` / `smile` / `grin`（张大嘴乐）/ `open`（惊）/ `o`（呆）/ `wobble`（使劲、晕）/ `flat`；眼睛有 `happy`（眯眼笑）、`dizzy`（旋涡眼）、`eR` 放大受惊。
- 写字时铅笔叼在嘴里，头一点一点。它没有手，所以这样写。
- 姿态统一由 `poseOn(up, tan)` 计算：知道“头顶朝哪”和“往哪走”，就能得出旋转角和左右朝向。爬茎、走叶子、倒挂花盘底、在纸轨道里绕圈都用同一套逻辑。

### 4. 世界布局（世界坐标，y 向上为负）
- 地面 y=0。向日葵茎在 x≈0，高 1350；花盘中心 (0,-1450)，是一个略微朝上的透视椭圆。
- **三个出错点，同时也是三个机关的位置**：
  - M1 / C1：左侧第一片叶子，叶尖约在 (-262,-292)，会被压弯。正下方地面上是**黄纸手风琴弹簧**。
  - M2 / C2：左边一根很高的草 (-520,0)，长 740。它会爬错成这根草，草被压弯把它放回地面。草尖上装了**黄纸杯**。
  - M3 / C3：花盘下沿的苞片，蜗牛倒挂在那里过不去。沿花盘左缘装了一条 **C 形黄纸轨道**，把蜗牛从花盘下面兜到花盘上面。

## 三、分镜（第二版，47.75 秒）

核心对比：**写在身上的纸条，风一吹就没了；自己造出来、装进世界里的机关，才靠得住。**
纸条只是引子。第 14 秒就进入做机关，后面约 70% 的时长都在讲机关。

| # | 新时间 | 镜头 | 内容 | 作用 |
|---|---|---|---|---|
| 1 | 0–4.5s | 特写 → 仰摇 → 回到蜗牛 | 抬眼望向日葵，思考泡泡里是它坐在花上看太阳升起 | 交代目标 |
| 2 | 4.5–8.85s | 叶子中景 | 眼睛盯着天，走出叶尖踩空，摔扁、晕圈。叼着铅笔写一张纸条（叶子、箭头、×），甩到壳上，得意 | 纸条登场 |
| 3 | 8.85–10.6s | 同一机位，稍微拉开 | **纸条刚贴上，一阵风就把它掀走了**。眼柄伸得老长去追，愣住 | 第 10 秒观众就明白：纸条靠不住 |
| 4 | 10.6–14.1s | 和第 2 镜同一构图 | 马上又从同一个叶尖掉下来。那张被风折成手风琴的纸条飘回来，眼柄一戳，纸条弹了起来，“！” | 纸不该贴在身上，而是可以做成东西 |
| 5 | 14.1–18.6s | 弹簧位 | 施工云团。第一版弹簧歪歪扭扭，一踩就塌，它被压成饼；第二版整整齐齐，一弹把它射出画面 | 机关 ① |
| 6 | 18.6–22.65s | 草丛全景 | 它爬错成高草，草被压弯把它放回地面。它就地在弯下来的草尖上施工，装了一个纸杯，草带着纸杯弹回去 | 在出错的地方装机关 ② |
| 7 | 22.65–26.75s | 茎 → 花盘底 | 快速爬到顶，倒挂在花盘底下过不去。施工只用 0.45 秒，C 形纸轨道铺好，闪一下光。它得意地冲镜头笑，然后手一滑又掉了下去 | 机关 ③ 越做越熟练，人却没变聪明 |
| 8 | 26.75–34.55s | 大全景（三个机关一起入画）→ 跟拍 | 天边微微发黄。最后一次照样走出叶尖踩空，于是弹簧 → 纸杯 → 草回弹 → 纸轨道绕过花盘边缘 → 翻滚着落到花盘上，背对着东方 | 错误就是开关，机关把它送了上去 |
| 9 | 34.55–41.25s | 花盘近景 | 太阳在身后升起，花瓣一片片被照黄。它先看见自己的影子，眼柄转到背后，看见太阳，转身，眯眼傻笑 | 高潮 |
| 10 | 41.25–47.75s | 近景 → 大全景 → 淡出 | **风又来了。** 很早以前那张“叶子”纸条被风卷着从它眼前飞过，一路飞远，它的眼睛只跟着看了一下，接着转头看自己的纸轨道：轨道在风里只轻轻一颤，稳稳挂着，还闪了一下光，它眯眼笑了。镜头拉到大全景：纸条飞没了，弹簧、草杯、纸轨道在阳光里都还在原处 | 把对比说完：纸条被吹走，机关还在 |

### 第二版改了什么
- **引子从 26.5 秒压缩到 14 秒**：只写一张纸条，贴上后马上被风吹走，紧接着用同一构图重犯同一个错。“纸条靠不住”在第 10 秒左右就讲明白了。
- **错误 2 和错误 3 不再各写一张纸条**，而是出错后当场在原地造机关。“装在它出错的地方”也因此看得更直接。
- **结尾不再写新纸条**。改为用同一种风做一次对照：旧纸条被吹走，它不去追；它造的纸轨道被吹得轻轻一颤但没掉，它看着轨道笑。最后一个画面是它的三个机关，而不是纸条。

## 四、取舍说明
- **只用象形图，不写字**：纸条上是“叶子 + 向下箭头 + ×”这类小图，静音、不分语言都能看懂。
- **机关用“施工云团”一笔带过**：这是经典卡通语言，笑点更直接。云团持续时间一次比一次短（0.9 → 0.6 → 0.6 → 0.45 秒），成品也从歪到正、从简单到复杂，用来表现“越做越熟练”。
- **连锁只用三级**（弹簧 → 草杯 → 纸轨道），每一级都正好对应一个出错点，因果一眼能看清。
- **全片压暗在黎明前的冷灰里**：黄纸始终是最亮的颜色，日出时整张画面第一次变暖。
- **删掉了纸鹤**：它在小尺寸下看起来像一顶皇冠，会造成误读。
- **剪辑方式**：`anim.js` 的 `scene()` 仍按分镜段各自的时间轴编写，由 `EDIT` 表把成片时间映射到这些分镜段；第一镜 1.33 倍速，第 7 镜里爬茎那一小段 1.5 倍速。新写的两段是“纸条被吹走”（`t≥100`）和新结尾（`t≥60`）。

## 五、文件
- `index.html` + `anim.js`：浏览器播放。空格暂停，左右方向键逐帧，底部可拖动时间轴。`?t=秒` 查看单帧。
- `render.js`：用 puppeteer-core 驱动 Edge 无头逐帧截取 canvas，通过管道交给 ffmpeg 编码成 mp4。`node render.js out.mp4` 渲染整片；`node render.js --times 1,2,3 dir` 抽帧到目录。
- `sheet.sh`：`sh sheet.sh 名字 t1,t2,...` 抽帧拼成一张联系表，用来检查。
- `snail_sunflower.mp4`：成片。
